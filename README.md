# ZX — India's Social Universe

Complete next-generation social networking platform combining:
- **Home**: Visual feed, multi-image carousels, 24-hour Stories, Story Highlights, and reactions.
- **ZX**: Text discussions, long-form posts, threads, polls, hashtags, mentions, and quote posts.
- **Search & Explore**: Real-time search across users, posts, hashtags, and videos.
- **ZX Shorts**: Vertical full-screen short-video feed with auto-play, view tracking, likes, comments, and saves.
- **ZX Messages**: Real-time WebSocket 1:1 & group messaging with attachments, read receipts, typing indicators, and message requests.
- **Creator Studio**: Real database analytics (`7D` / `30D` / `All`) with zero fabricated metrics.
- **Admin Dashboard**: Secure first-owner setup, user management, content moderation, reports, verification reviews, hashtag moderation, announcements, and audit logs.

## Zero-Start Guarantee

ZX launches with:
- **0 Users**
- **0 Posts**
- **0 Followers**
- **0 Stories**
- **0 Videos**
- **0 Comments**
- **0 Messages**

The first real person who registers becomes the first member of ZX.
